# QR コード画像

各クライアント（参加者・観客の画面）の右下にある「QRコード」ボタンで表示する画像です。

## 置き方

このフォルダ（`client/public/`）に **`qr.png`** という名前で配置してください。

- 配信パス: `/qr.png`（参照先は `client/src/components/QrButton.jsx` の `QR_SRC`）
- 推奨: 正方形・余白込みの QR（長辺 600px 以上）。背景は白。
- 別の拡張子（`qr.svg` など）を使う場合は `QrButton.jsx` の `QR_SRC` を合わせて変更してください。
- 未設置・読み込み失敗の場合は、モーダルに「QRコードは準備中です」と表示されます（画面は壊れません）。

## 表示場所

- 参加画面（参加前）と、ジオゲッサー／ゴッドタレントのプレイ画面の右下にボタンが出ます。
- 運営画面・投影（ランキング）画面には表示されません。
