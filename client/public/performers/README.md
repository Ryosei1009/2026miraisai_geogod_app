# 出演者の顔写真

ゴッドタレントのランキング表彰台で表示する顔写真をここに置きます。

- ファイル名は出演者IDに合わせます（`server/index.js` の `performers` 配列の `id`）。
  - `1.jpg` … No.1
  - `2.jpg` … No.2
  - `3.jpg` … No.3
  - `4.jpg` … No.4
  - `5.jpg` … No.5（篠原 諒成）
- 正方形に近い画像を推奨（丸く切り抜かれて表示されます）。
- `.jpg` 以外を使う場合は `server/index.js` の各 `photo` パスの拡張子を変更してください。
- ファイルが無い／読み込めない場合は、自動的に空の丸（プレースホルダー）で表示されます。
