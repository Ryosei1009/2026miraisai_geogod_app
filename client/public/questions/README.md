# 問題の写真（答え発表用）

ジオゲッサーの「答え発表」（`?admin=1&rank=1` で運営が「答えを表示」を押した後）で表示する写真を置く場所です。

## 命名規則

ファイル名は `q{問題ID}.jpg` です。問題IDはサーバー (`server/index.js`) の `questions` 配列の `id` と対応します。

| ファイル | 問題 | 場所 |
| --- | --- | --- |
| `q1.jpg` | お試し | 東京駅 |
| `q2.jpg` | 日本1 | 姫路城 |
| `q3.jpg` | 日本2 | 金閣寺 |
| `q4.jpg` | 日本3 | 阿蘇山 |
| `q5.jpg` | 日本4 | 弘前城 |
| `q6.jpg` | 日本5 | 松山城 |
| `q7.jpg` | 世界1 | エッフェル塔 |
| `q8.jpg` | 世界2 | 自由の女神 |
| `q9.jpg` | 世界3 | コロッセオ |
| `q10.jpg` | 世界4 | ギザの大ピラミッド |
| `q11.jpg` | 世界5 | シドニー・オペラハウス |

## 仕様

- このフォルダは `client/public/` 配下なので、`/questions/q2.jpg` のように絶対パスで配信されます（パスは `server/index.js` の各問題の `photo` フィールドで指定）。
- 写真が未設置・読み込み失敗の場合は、答え発表画面に「写真は準備中です」と表示されます（画面は壊れません）。
- 推奨: 横長（16:9 程度）、長辺 1600px 程度の `.jpg`。別の拡張子を使う場合は `server/index.js` の `photo` を合わせて変更してください。
